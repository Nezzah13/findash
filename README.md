# 💳 МойКошелёк - финансовый дашборд

Учебная панель личных финансов на **React + TypeScript** с использованием библиотеки компонентов **Ant Design** и графиков **Recharts**. Показывает баланс, расходы по категориям, динамику доходов и расходов, историю операций и банковские карты.

> 🔗 **Демо:** (добавлю позже)


## Возможности

- 📊 Карточки-показатели: баланс, расходы, поступления, бонусы
- 🍩 Пончиковая диаграмма расходов по категориям (Recharts)
- 📈 График доходов и расходов по месяцам (Recharts)
- ⚡ Плитки быстрых действий
- 🧾 История операций: таблица с поиском, категориями и цветными суммами
- 💳 Страница банковских карт
- 🧭 Боковое меню и маршрутизация между разделами
- 🇷🇺 Полностью на русском, суммы в рублях

## Стек

- **React 18** + **TypeScript**
- **Ant Design 5** - библиотека UI-компонентов (Layout, Menu, Table, Card, Tag и др.)
- **Recharts** - диаграммы
- **React Router** - маршрутизация
- **Vite** - сборка и dev-сервер

Данные захардкожены в папке `src/data` - так как проект без бэка

## Запуск

Нужен Node.js 18+.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production-сборка
npm run preview  # просмотр сборки
```

## Структура

```
src/
├── components/   # AppLayout, StatCard, ActionTiles, графики, список операций
├── pages/        # Дашборд, История, Мои карты
├── data/         # захардкоженные данные
├── types/        # типы TypeScript
├── utils/        # форматирование рублей и дат
└── styles/       # глобальные стили
```
